# Rishi math study

Fourth-grade math practice that moves from guided examples to independent reasoning. Use the four booklets one at a time in the order below.

## Student materials

| Booklet | Focus | Core sections |
| --- | --- | --- |
| [Part 1](output/booklets/part_1_expressions.md) | Simplifying single-side expressions | 1–7 |
| [Part 2](output/booklets/part_2_addition_subtraction_equations.md) | Addition and subtraction equations | 8–20 |
| [Part 3](output/booklets/part_3_groups_and_factors.md) | Equal groups, common factors, and brackets | 21–28 |
| [Part 4](output/booklets/part_4_multiplication_division_equations.md) | Multiplication, division, and multi-step equations | 29–40 |

Keep the [revision reminder](output/revision_reminder.md) nearby. The [complete workbook](output/complete_workbook.md) combines all four parts, the reminder, answers, and workflow. There are 40 core sections plus additional guided practice; printed page counts are larger because longer sections have extra working pages.

## Viewing and printing

Open the Markdown files in Typora for the intended math rendering, including diagonal cancellation. Print on Letter paper at 100% scale with printer headers and footers off. Check print preview for page breaks, symbol rendering, and writing space; layout depends on the Typora theme. GitHub preview may not reproduce the print styling.

## Rules for future changes

Use 𝑥 for the unknown, × for multiplication, and fraction notation for division (stacked fractions in math blocks; a/b in text). Keep unchanged terms and equals signs aligned. Show every operation explicitly, place common factors before brackets, and gradually fade the prompts. Follow the full workflow before creating a new tutorial.

The workflow file is the source for reusable instructions; mirror it in the complete workbook and parent file. When changing exercises, update the relevant booklet, complete workbook, answers, and revision reminder together. Verify the mathematics and inspect Typora print preview.
